# `security/evidence/` — local-only, never commit

Firebase / GCP security-evidence snapshots (`firebase-security-evidence-*.json`)
are generated by `scripts/ops/collect-firebase-security-evidence.mjs` for local
review only. **They must never be committed.**

A committed snapshot leaks recon-grade data about the production project: the
full IAM policy (bindings, roles), human/owner email addresses, service-account
identities, the project number, and Secret Manager resource names (whose IDs can
encode UIDs/tenant data). That is exactly the map an attacker wants.

Controls:

- These files are git-ignored (`security/evidence/firebase-security-evidence-*.json`).
- The collector redacts bearer tokens, Google access tokens, API keys, IAM
  principals (`user:`/`serviceAccount:`/`group:`/`domain:`), service-account and
  human emails, and Secret Manager resource names before writing output.
- If a snapshot is ever committed again, remove it from history (see
  `docs/security/PUBLIC_REPO_HISTORY_PURGE_RUNBOOK.md`) and treat the exposed IAM
  topology as recon-compromised (review/rotate as appropriate).
