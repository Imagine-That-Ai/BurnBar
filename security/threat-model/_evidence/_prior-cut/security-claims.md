## Explicit Non-Claims

- BurnBar does not protect plaintext visible on a compromised endpoint.
- BurnBar does not prevent a user from intentionally sending data to a model provider.
- BurnBar does not guarantee anonymity or full metadata privacy.
- BurnBar does not guarantee Signal-level security for Hermes Gateway.
- BurnBar does not guarantee full forward secrecy or post-compromise recovery for all relay paths.
- BurnBar does not protect against all malicious model behavior.
- BurnBar does not prevent screenshots, clipboard capture, OS malware, shoulder surfing, or local process inspection.
- BurnBar does not guarantee confidentiality from a fully compromised paired device.
- BurnBar does not currently prove all local storage is encrypted.
- BurnBar does not prove all production cloud/IAM controls from repository evidence alone.
