# GTM Master Plan — OpenBurnBar Commercial Launch

**Status as of 2026-05-30:** execution plan and launch bar, not a launch-complete stamp. `launch-evidence/LAUNCH_DONE.md` is the only final done marker, and it is valid only after the Definition of Done in section 6 is fully evidenced.

**Scope:** collapse OpenBurnBar commercial packaging into Free Local, BurnBar Cloud, and BurnBar Cloud Pro; implement the two-tier entitlement/billing/allowance model across Stripe, Apple, Google Play, Firebase, website, app paywalls, monitoring, paid proof, canary, and rollback.

**Citation shorthand used below:** Doc 1 = positioning and category strategy; Doc 2 = existing entitlement/SKU ladder; Doc 3 = safety budgets, kill-switches, and runbooks; Doc 4 = unit economics and COGS model; Doc 5 = final pricing/tier recommendation.

# 1. Locked Decisions

## 1.1 Margin target used for all pricing decisions

**ASSUMPTION — explicit because the docs do not name a numeric gross-margin target:** launch pricing must satisfy:


| Tier              | Target                                                                                                                                                        |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| BurnBar Cloud     | ≥80% gross margin even at capped-tail usage under Apple’s post-$1M 30% take                                                                                   |
| BurnBar Cloud Pro | ≥50% gross margin at median, power, and capped-tail hosted-vision usage under Apple’s post-$1M 30% take, after prepaid top-ups and the commercial monthly cap |


This is stricter than the docs’ minimum “do not lose money on the engaged user” rule and directly addresses the Doc 5 constraint that a low flat Tier 2 loses money without allowance/cap control. Doc 5 also requires the $5/day Computer Use, 5 GB/day media, $1500/$2500 Computer Use, and $600/$1000 media kill-switches to remain non-negotiable safety floors.

## 1.3 Tier 2 cost-containment design

**Locked design: subscription + included allowance + prepaid top-ups + tighter commercial monthly cap. No unlimited flat Tier 2.**


| Cost vector                         | Included in BurnBar Cloud Pro                                   | Paid top-up                                              | Hard commercial cap                         | Safety floor retained                                                                                                                    |
| ----------------------------------- | --------------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Hosted Agent Control vision actions | **500 hosted actions / billing month**                          | **$4.99 per 100 hosted actions**, prepaid before use     | **2,000 hosted actions / billing month**    | Existing Computer Use safety envelope remains: 50 actions/run, 200 actions/day, $5/user/day, global $1500 soft / $2500 hard kill-switch. |
| Floo relay-accounting bandwidth     | **50 relay-accounting GB / billing month**                      | **$4.99 per 50 relay-accounting GB**, prepaid before use | **300 relay-accounting GB / billing month** | Existing media safety envelope remains: 5 GB/day/user and global $600 soft / $1000 hard kill-switch.                                     |
| BYOK / user-funded model route      | Unlimited by OpenBurnBar billing, subject to safety permissions | No OpenBurnBar top-up required                           | Safety caps still apply to control actions  | User pays their own model provider, so hosted-vision COGS is $0 to OpenBurnBar.                                                          |


The top-up price is deliberately above the Doc 5 minimum of “≥$0.02/action” because Doc 4 pegs hosted Computer Use at ~$0.013/action, and Apple can later take 30%. The commercial cap is tighter than the underlying safety floor; Doc 4 explicitly lists tighter per-user caps as a Tier 2 cost lever.

### Tier 2 margin proof

All subscription revenue below uses Apple as the conservative channel. Stripe is better, and Google Play small-business economics match Apple 15% in Doc 4.


| User profile                 | Usage model                                                     | Net revenue at Apple 15% | Net revenue at Apple 30% | COGS using Doc 4 numbers                         | GM at 15% | GM at 30% | Pass? |
| ---------------------------- | --------------------------------------------------------------- | ------------------------ | ------------------------ | ------------------------------------------------ | --------- | --------- | ----- |
| Median T2                    | 400 actions/mo, 2 relay hrs, no top-up                          | $21.24                   | $17.49                   | $5.55                                            | 73.9%     | 68.3%     | Yes   |
| Power T2                     | 1,500 actions/mo, 15 relay hrs, 10 action top-ups               | $63.66                   | $52.42                   | $20.80                                           | 67.3%     | 60.3%     | Yes   |

Doc 4’s uncapped “power” profile is $20.80 total COGS, and its full existing safety ceiling can allow much higher spend; this is exactly why BurnBar Cloud Pro is not launched as unlimited flat-rate.

## 1.5 Free tier and trial


| Decision          | Locked value                                                                              | Rationale                                                                                                                                        |
| ----------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Free tier         | **Pure local only. No free OpenBurnBar-operated cloud teaser.**                           | Free local costs the operator $0 because there is no cloud footprint, and the local-first story is core to positioning.                          |
| Trial             | **14-day BurnBar Cloud trial only.** No BurnBar Cloud Pro trial.                          | Doc 5 recommends keeping Free local plus a 14-day Tier 1 trial; Tier 2 includes the variable-cost features, so no free Agent Control/Floo trial. |
| Trial eligibility | One trial per Firebase UID, per Apple/Google/Stripe customer, and per device family hash. | ASSUMPTION to prevent trial abuse.                                                                                                               |
| Trial conversion  | Trial converts to BurnBar Cloud monthly unless the user chooses annual before trial end.  | Keeps Tier 1 as the cheap conversion step.                                                                                                       |
| Pro upgrade       | No trial; first paid month includes the 500 hosted-action and 50 relay-GB allowance.      | Prevents free hosted-vision burn.                                                                                                                |

| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |

| Legacy $4.99 Hosted Quota Sync            | Grandfather existing subscribers indefinitely into Tier 1 Group-A access while they keep paying. Do not offer this SKU to new buyers. On cancel/lapse, resubscribe only at BurnBar Cloud $7.99/$79.    |
| Orphan $9.99 media-only SKU               | Retire / do not create for new sale. If it exists in any store, mark “not available for new purchases.” Existing entitlements, if any, continue until natural expiry, then migrate to Cloud Pro offer. |
| Orphan standalone $14.99 Computer Use SKU | Retire / do not create for new sale. Existing test fixtures stay test-only.                                                                                                                            |
| Stripe compatibility                      | Set legacy `STRIPE_BURNBAR_PRO_PRICE_ID` to the BurnBar Cloud monthly price while adding explicit four-price config for Cloud/Cloud Pro monthly/annual and top-up SKUs.                                |
| Store channel availability                | Both paid tiers must be purchasable through Stripe web, Apple IAP, and Google Play. Top-ups must also be prepaid on all channels before hosted-vision/relay overage is allowed.                        |


Doc 2 shows the existing entitlement/SKU ladder and the current gating quirk where `hosted_quota_sync` is accepted for Group-A gates; Doc 5 recommends folding the orphan SKUs into two tiers and grandfathering legacy $4.99 users.

## 1.7 Default Computer-Use vision model

**Locked default: Claude Sonnet 4.5 hosted vision at the documented ~$0.013/action.**

Reason: Doc 4’s authoritative Tier 2 economics are built around Sonnet 4.5, and switching to a cheaper model would introduce a new cost/quality assumption not quantified in the research package. Cost safety is handled by prepaid allowances and caps, not by changing the default model.

# 6. Definition of Done Checklist

The launch is **done** only when every item is objectively true:

## Pricing and products

- Public tiers are exactly: OpenBurnBar Local $0, BurnBar Cloud $7.99/mo or $79/yr, BurnBar Cloud Pro $24.99/mo or $249/yr.
- BurnBar Cloud includes Group A only.
- BurnBar Cloud Pro includes Group A + Floo + Agent Control.
- Cloud Pro allowance is live: 500 hosted actions/month, 50 relay-accounting GB/month, $4.99 top-ups, 2,000 hosted-action monthly cap, 300 relay-GB monthly cap.
- Legacy $4.99 Hosted Quota Sync remains grandfathered and is not available to new buyers.
- $9.99 media-only and $14.99 standalone Computer Use are not sold to new users.

## Channels

- Stripe web can purchase Cloud monthly/annual, Cloud Pro monthly/annual, Agent Control 100-action top-up, and Floo 50GB top-up.
- Apple IAP can purchase the same tier set and top-ups.
- Google Play can purchase the same tier set and top-ups.
- Subscription restore works on iOS and Android.
- Refund/cancel/chargeback revokes or expires entitlements through reconciliation.

- Legacy $4.99 subscriber can access Group A only.
- `burnbar_pro` can access Group A only.
