### Cross-platform contract S2 (Swift) must mirror — `projectKeyHash`
`projectKeyHash` = `CloudVaultCrypto.tokenHashes(<normalized>, vaultKey, limit:1).first`, where `<normalized>` = the project name **lowercased and stripped to ASCII `[a-z0-9]` only** (spaces/punctuation/Unicode removed), requiring `length >= 2` else omit. Swift must feed the identical ASCII-normalized single string to `CloudVaultCrypto.tokenHashes(for:keyData:)` so the 16-byte/32-hex HMAC trapdoor matches byte-for-byte. (Contract §1 left the exact normalization unspecified; this pins it.)
