## 📐 Grid Layout & Frame Standard
To ensure smooth alignment and integration across macOS, iOS, Android, and Web platforms:
- **Hero Medallions**: `512x512` base frame, 12px safe margin.
- **Shield Crests**: `256x256` base frame, 10px safe margin.
- **Member Badges**: `128x128` base frame, 8px safe margin.
- **Trust Badges**: `80x80` base frame, 6px safe margin.
- **Capability Icons**: `64x64` base frame, 4px safe margin.
