# Roadmap

## Now (v1.0)

- Trust labels showing data confidence per provider (Exact / Estimated / Planned)
- Confidence indicators on cost figures
- Better empty states when no log files are found
- Open source packaging (README, CONTRIBUTING, LICENSE)

## Next (v1.1)

- More parser implementations: Copilot, Aider, Cursor
- Cost export to CSV
- Notification alerts when spend exceeds a threshold

## Later

- Team usage sharing (aggregate costs across machines)
- Budget tracking with configurable limits
- Historical trend analysis and charts
- API integrations for providers that support billing APIs
