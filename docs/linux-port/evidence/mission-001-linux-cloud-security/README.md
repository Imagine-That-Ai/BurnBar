```bash
rg -n "fixture-[a-z]+-(secret|token)|sk-ant-[a-z]+|[a-z]+@example\\.com|/home/[a-z]+/\\.config/openburnbar/token\\.json" docs/linux-port/evidence/mission-001-linux-cloud-security/linux-security-evidence.json docs/linux-port/evidence/mission-001-linux-cloud-security/blocked-production-evidence.md
```

The harness source builds sensitive fixture values at runtime and never prints them. The product SecretStore API returns secret metadata for token custody evidence; raw secret values stay in backend memory.
