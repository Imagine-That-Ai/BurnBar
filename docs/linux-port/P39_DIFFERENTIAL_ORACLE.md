# P-39 Differential Oracle

`run-platform-differential.mjs` compares two JSON evidence artifacts from the
same product contract. It is intentionally evidence-scoped: it does not launch
either app, infer missing behavior, or turn an exact fixture comparison into a
parity certification.

## Usage

```bash
node scripts/linux-port/run-platform-differential.mjs \
  --macos path/to/macos-evidence.json \
  --linux path/to/linux-evidence.json \
  --ignore '$.metadata.generatedAt' \
  --out docs/linux-port/evidence/differential/report.json
```

The report contains a stable SHA-256 for each normalized artifact, the sorted
ignored path list, and path-level differences. Object keys are sorted before
hashing. Credential-shaped keys (`token`, `password`, `secret`, `apiKey`,
authorization, and related forms) are replaced with `[REDACTED]` before either
the report or hash is produced. An ignored path is replaced with `[IGNORED]` on
both sides; missing or extra paths still fail.

Exit codes are deliberately machine-friendly:

- `0`: `exact_match`
- `1`: `differences` requiring review
- `2`: `invalid` input or command usage

## Acceptance boundary

Feed the oracle artifacts generated by the same contract version and release
head. Review every non-ignored difference; do not add an ignore merely to make
the command green. The oracle complements installed runtime and accessibility
evidence and cannot replace them.

## QA

```bash
node --test scripts/linux-port/run-platform-differential.test.mjs
node scripts/linux-port/run-platform-differential.mjs --help
```

The focused suite covers exact matches, deterministic key ordering, credential
redaction, ignored volatile fields, nested mismatches, missing/malformed input,
report output, and all exit classes.
