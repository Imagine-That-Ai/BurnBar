## Sanity check vs the audit's sampled ratios

The WS-A audit sampled the API surface and estimated roughly **65% cross-module /
20% internalizable / 15% dead**. The full measurement over all 2,092 uniquely
attributable public type names lands at **80.5% cross-module / 8.9% internalizable
(5.6% test-only + 3.3% own-module-only) / 7.3% dead** (+3.2% ambiguous, excluded).
The delta is real and directionally expected: the classifier's word-boundary grep
counts ANY textual mention outside the module — including mentions inside comments
and string literals of OTHER files (only the DECLARING side is comment-stripped) —
so **cross-module is an upper bound and dead/own-module-only are lower bounds**.
The sampled 65/20/15 likely read usage sites more precisely than a grep can.
Consequence for planning: the A-packet work-lists below (153 dead + 70
own-module-only + 117 test-only names) are the CONSERVATIVE floor of the curation
opportunity; executors may internalize more as they verify neighboring symbols.
